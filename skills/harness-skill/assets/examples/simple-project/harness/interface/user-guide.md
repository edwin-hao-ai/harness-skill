# User Guide · TaskFlow

TaskFlow 帮你的小团队把任务状态沉淀到一块共享看板上，从而少开同步会。本指南面向**团队负责人**。

## 适用用户

### 团队负责人

你负责分配任务、跟踪进度。用 TaskFlow 后，你不再靠追问了解状态——看板就是答案。

**你会用到：**

- 分配任务（指派、设优先级）
- 查看整体进度、识别阻塞

## 三步上手

1. **建团队、拉成员**：建好团队后邀请成员加入，每人有自己的身份。
2. **创建并分配任务**：新建任务 → 指派成员 → 设优先级，任务进入「待办」。
3. **接 Slack（强烈建议）**：连接后，分配/状态变更/被 @ 会推到 Slack，
   这样大家不盯着看板也不会漏事——这是"异步替代会议"的关键一环。

## 日常用法

- **看板替代站会**：每天扫一眼三列（待办/进行中/完成），卡在「进行中」太久的就是要关注的。
- **评论替代追问**：别私聊问进度，直接在任务下评论并 `@` 对方，讨论留痕、可追溯。
- **冲突提示**：若看到"该任务刚被他人更新"，说明有人同时在动它，看板会自动刷新到最新。
